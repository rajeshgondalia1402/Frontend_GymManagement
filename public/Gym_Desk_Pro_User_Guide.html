1. What is Gym Desk Pro?

Gym Desk Pro is an online gym management application that helps gym owners run their entire gym operations smoothly from a single platform. It covers:

  • Member Management — Add members, track memberships, renewals, and payments
  • Trainer Management — Add trainers, assign them to members, settle salaries
  • Diet & Exercise Plans — Create and assign plans to members
  • Attendance Tracking — Track daily member attendance
  • Finance — Track expenses, income, pending payments, and salary settlements
  • Inquiries — Manage prospective member leads and follow-ups
  • Reports — Get a bird's-eye view of your gym's performance

2. User Roles

Gym Desk Pro has three user roles. Each role sees a different dashboard and menu.

Role Who Are They? What Can They Do?
Gym Owner The person who owns/runs the gym Full control — members, trainers, finances, plans, attendance, reports
Trainer A fitness trainer at the gym View assigned PT members, check salary, download salary slips
Member A gym member View membership, diet plan, exercise plan, attendance, dashboard

Steps to Add a Member:

  1. Fill in Personal Information — First Name, Last Name, Mobile Number (required)

4.4 Membership Renewal

When a membership expires or is about to expire, renew it from the Members page.

Steps to Renew:

  1. Go to Sidebar → Members
  2. Find the member (filter by "Expiring" status for quick access)
  3. Click the "Renew" button from the action menu (⋮)
  4. In the Renewal Dialog: select new Course Package
  5. New dates auto-calculate. Apply any discount if needed
  6. Select Payment Mode (Cash / Card / UPI / Online)
  7. Enter the amount paid (partial payment is OK — balance is tracked)
  8. Click "Renew" to confirm
⚠️ Note: Renewal types include Standard, Early (before expiry), Late (after expiry), Upgrade (longer package), and Downgrade (shorter package).

4.5 Balance Payment (Partial Payment)

  1. Go to Members → find the member
  2. Click the "Payment" button from the action menu
  3. Select Payment For: Regular or PT Membership
  4. Enter Payment Date and Amount Paid
  5. Select Payment Mode
  6. Receipt number is auto-generated (e.g., RCP-001)
  7. Click "Save"
💡 Tip: The system tracks all partial payments and calculates the remaining balance automatically. You can view the complete payment history on the member's detail page.

4.6 Personal Training (PT) Membership

PT Membership is an add-on on top of a regular membership.

Adding PT Membership:

  1. Go to Members → Find the member → Click "Add PT"
  2. Select a PT Course Package (e.g., "1 Month PT")
  3. Select a Trainer to assign
  4. Dates, fees auto-calculate. Apply discount if needed
  5. Add Goals (Weight loss, Muscle building, etc.)
  6. Click "Save"
PT ActionDescription
Edit PTUpdate trainer, dates, fees, goals
Pause PTTemporarily freeze PT (remaining sessions preserved)
Remove PTCompletely remove PT add-on (regular membership remains)

4.7 Managing Trainers

Navigate to Sidebar → Trainers

Adding a New Trainer:

  1. Click "+ Add Trainer"
  2. Fill in: Name, Email, Phone (required), DOB, Gender
  3. Set Designation (Senior Trainer, Yoga Instructor, etc.)
  4. Set Specialization, Experience, Joining Date
  5. Enter Monthly Salary amount
  6. Upload Photo and ID Proof
  7. Click "Save"

💡 Tip: After saving, the trainer gets login credentials (mobile number + temporary password) to access their own Trainer Dashboard.

4.8 Member Inquiries (Leads)

Navigate to Sidebar → Member Inquiries to track prospective members.

Adding a New Inquiry:

  1. Click "+ New Inquiry"
  2. Fill in: Full Name, Contact Number (required)
  3. Set Inquiry Date, how they heard about you (Walk-in, Social Media, Referral)
  4. Add any Comments about their interests
  5. Set a Follow-up Date
  6. Click "Save"
💡 Tip: Follow-ups appear on your Dashboard so you never miss one. Update inquiries as conversations progress, and convert them to members when they join.

4.10 Exercise Plans

Navigate to Sidebar → Exercise Plans

Creating an Exercise Plan:

  1. Click "+ Create Plan"
  2. Enter Plan Name (e.g., "Beginner Full Body")
  3. Add exercises for each day of the week (Mon–Sat)
  4. For each exercise: set Name, Sets, Reps, Duration
  5. Click "Save Plan"

Assigning to a Member:

  1. Go to Members → Click on a member
  2. Click "Assign Exercise Plan"
  3. Select the plan, choose which days it applies
  4. Set Start/End date → Click "Assign"

4.12 Attendance Tracking

Navigate to Sidebar → Reports → Attendance

Manual Attendance Entry:

  1. Click the "Manual Entry" tab
  2. Select the Member from dropdown
  3. Set the Date
  4. Enter Check-in Time and Check-out Time
  5. Enter a Reason (e.g., "Biometric not working")
  6. Click "Save"
💡 Tip: If biometric devices are set up, attendance is recorded automatically when members check in/out using their fingerprint.

4.13 Expense Management

Setting Up Expense Categories (One-time):

  1. Go to Master → Expense Group Master
  2. Click "+ Add Group"
  3. Add groups like: Rent, Equipment, Utilities, Maintenance

Recording an Expense:

  1. Go to the Expenses page
  2. Click "+ Add Expense"
  3. Fill in: Date, Name, Group, Amount, Payment Mode
  4. Upload any bill/receipt attachments
  5. Click "Save"

4.14 Trainer Salary Settlement

Steps to Settle Salary:

  1. Go to Salary Settlements
  2. Click "+ New Settlement"
  3. Select the Trainer and Salary Month
  4. System auto-fills: Monthly Salary, Present Days, Absent Days
  5. Enter Discount Days (approved leaves)
  6. Add any Incentive (PT Training, Protein Sales, Referral)
  7. Review Final Payable Amount
  8. Select Payment Mode → Click "Save"

7. Frequently Asked Questions

General

QuestionAnswer
How do I get my login credentials?Gym Owners receive them from Admin. Trainers & Members receive them from the Gym Owner.
I forgot my passwordContact your Gym Owner (Trainers/Members) or Admin (Gym Owners) for a password reset.
Can I use this on mobile?Yes! Gym Desk Pro is fully responsive and works on phones, tablets, and desktops.

For Gym Owners

QuestionAnswer
How do I get started?1) Set up Master Data → 2) Add Trainers → 3) Add Members → 4) Create Diet/Exercise Plans → 5) Track Attendance
Regular vs PT membership?Regular = standard gym access. PT = add-on with a personal trainer assigned. Members can have both.
Can I give discounts?Yes! Each package has a max discount limit. Apply up to max + an extra discount.
What if member pays in installments?Use Balance Payment to record each installment. The system tracks remaining balance automatically.
Can I export data?Yes! Export member list to Excel/CSV from the Members page.

For Trainers

QuestionAnswer
Can I see all gym members?No. You can only see members assigned to you for Personal Training.
How do I check my salary?Go to Salary Settlements. Filter by date and download PDFs.

For Members

QuestionAnswer
Can I change my diet/exercise plan?No. Plans are assigned by your Gym Owner/Trainer. Contact them for changes.
How do I check if my membership is expiring?Your Dashboard shows the expiry countdown. The Membership page has all details.
How do I mark attendance?If biometric is set up, check in via fingerprint. Otherwise, the Gym Owner records it manually.
